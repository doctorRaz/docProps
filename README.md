# docProp

Утилита для чтения, записи и очистки свойств DWG-документа в nanoCAD.

Проект предназначен для работы со стандартными и пользовательскими свойствами документа и поддерживает обмен свойствами через файлы **INI** и **XML**, а также импорт из таблиц MultiCAD.

## Возможности

- чтение свойств текущего DWG-документа;
- экспорт свойств документа в файл INI или XML;
- импорт свойств из файла INI или XML в текущий DWG-документ;
- импорт свойств из таблицы MultiCAD;
- очистка всех свойств документа;
- раздельная очистка стандартных и пользовательских свойств.

### Свойства документа

Поддерживаются следующие стандартные свойства:

- Title — название документа;
- Subject — тема;
- RevisionNumber — номер версии/ревизии;
- LastSavedBy — последний сохранивший документ;
- Keywords — ключевые слова;
- HyperlinkBase — базовый адрес гиперссылок;
- Comments — комментарии;
- Author — автор.

Кроме стандартных свойств поддерживаются **пользовательские свойства** с произвольными именами.

## Команды nanoCAD

| Команда | Назначение |
|---|---|
| `drz_docProps_export` | Экспорт свойств текущего DWG-документа в файл INI или XML |
| `drz_docProps_import` | Импорт свойств из файла INI или XML в текущий DWG-документ |
| `drz_docProps_import_tbl` | Импорт свойств из таблицы MultiCAD в текущий DWG-документ |
| `drz_docProps_clear_all` | Удаление всех свойств из текущего DWG-документа |
| `drz_docProps_clear_standard` | Удаление стандартных свойств из текущего DWG-документа |
| `drz_docProps_clear_custom` | Удаление пользовательских свойств из текущего DWG-документа |
| `drz_docProps_cmdInfo` | Вывод информации о командах сборки |

## Форматы обмена

INI и XML являются официальными и равнозначными форматами обмена свойствами документа.

Формат определяется расширением файла:

- `.ini` → INI;
- `.xml` → XML.

При экспорте пользователь может выбрать имя и расширение файла. При импорте формат определяется по расширению выбранного файла.

### INI

INI-файл содержит две основные секции:

- `StandardDocProperty` — стандартные свойства документа;
- `CustomDocProperties` — пользовательские свойства.

Пустое значение стандартного свойства при импорте не перезаписывает существующее значение в DWG. Это позволяет изменять отдельные свойства без необходимости задавать остальные.

### XML

XML-файл содержит сериализованное представление объекта свойств документа и используется для сохранения и восстановления набора стандартных и пользовательских свойств.

## Импорт из таблицы MultiCAD

Команда `drz_docProps_import_tbl` получает таблицу MultiCAD по имени. Если таблица с указанным именем не найдена или имя не задано, предлагается выбрать таблицу непосредственно на чертеже.

При наличии нескольких таблиц с одинаковым именем импорт по имени не выполняется — таблица выбирается на чертеже.

## Установка

1. Распакуйте архив релиза в доступный каталог.
2. Добавьте файл `drzTools.package` из распакованного архива в автозагрузку nanoCAD.
3. Перезапустите nanoCAD.
4. Для проверки загрузки выполните команду `drz_docProps_cmdInfo`.
